# Filtro Gauss

Este repositório contém código e dados para experimentos com filtro gaussiano aplicado em imagens. As pastas seguem a mesma estrutura geral, a única diferença relevante entre os relatórios é a estratégia de paralelização:

- `relatorio1`: versões serial e paralela usando OpenMP.
- `relatorio2`: versões serial e paralela usando MPI (distribuído).
